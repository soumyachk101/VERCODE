Changelog

Every release in order, newest at the top, oldest at the bottom — the version, the date, and what changed, so a team can jump to the version they actually run.

2026-10-23v0.1.0

The documentation package + the workspace

The doc set and the shared workspace landed: 64 product docs, a 12-doc website package, and packages/contracts as the single source of truth for plan, finding, and webhook shapes.

Added

  • The documentation package: 64 docs across PRODUCT, TECHNICAL, DATABASE, API, SECURITY, DESIGN, TESTING, OPERATIONS, BUSINESS, and IMPLEMENTATION, each validated for cross-reference consistency in docs/DOCUMENTATION_REVIEW.md.
  • The website spec: 12 docs in docs/WEBSITE/ — the P2 launch surface's IA, content schemas, structured-data and SEO/AEO/GEO rules, the route list in docs/WEBSITE/INFORMATION_ARCHITECTURE_AND_PAGES.md.
  • packages/contracts as the single source of truth: Zod schemas for plans, findings, jobs, and webhooks that every app and package imports from — a shape change is one edit, not ten re-declarations.
  • The known-limitations register: L-1 through L-10 in the repo README "Known limitations", each with a landing phase — deferred items are documented, not silently absent.
2026-10-22v0.0.1

Scaffold

The repo is a working scaffold: docs + contracts + a dev-stack; the live pipeline ships behind gate-13.

Added

  • The pnpm monorepo: apps/web (the Next.js dashboard) + apps/api + apps/worker, 12 packages, and a Docker Compose dev-stack.
  • The Tailwind-4 + Next-15 dashboard surface: the six product views — overview, review detail, security rollup, repositories, rules, usage, audit — built against mocked data.
  • The test lanes: vitest unit/integration + Playwright E2E; the live external integration is a separate credentialed lane. The dev-stack runs on mocks, so a live PR review is not yet verified — L-8 in the README "Known limitations", marked blocked, not claimed.
  • The docs + contracts scaffold: a working pipeline design in docs/TECHNICAL/REVIEW_ENGINE_SPEC.md and the shared shapes in packages/contracts, with the L-1 through L-10 register tracking every deferred item.

The docs behind these releases: the rules and pipeline docs and the quota docs.
