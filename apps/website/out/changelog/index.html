2026-10-24v0.0.0

Added

  • The apps/website static export: 30 routes — the marketing pages (/, /features, /pricing, /faq, /about), the 9-topic docs hub, the 2-entry changelog feed, the 2-post blog, and the 5 legal pages (docs/WEBSITE/INFORMATION_ARCHITECTURE_AND_PAGES.md §1's WFR-101 route set).
  • The 16-question FAQ (docs/WEBSITE/CONTENT_SCHEMAS.md §4): the visible answers and the FAQPage JSON-LD both render from one source (src/lib/faq.ts), byte-equal by construction (the docs/WEBSITE/SEO_AEO_GEO.md §3 consistency rule).
  • The 4-plan pricing page + the quota table, generated from content/pricing/pricing.json (the docs/WEBSITE/INFORMATION_ARCHITECTURE_AND_PAGES.md §3.3 "a drift is structurally impossible" rule — the numbers are generated, not typed).
  • The machine-readable layer: the sitemap.xml + robots.txt + llms.txt + llms-full.txt generators (apps/website/src/lib/llms.ts, the docs/WEBSITE/TECHNICAL_ARCHITECTURE.md §1 build-time emission) and the single-source JSON-LD generator (apps/website/src/lib/schema-generator.ts, the docs/WEBSITE/TECHNICAL_ARCHITECTURE.md §4.1 "the only JSON-LD emitter").
  • The anti-slop lint gate: the DESIGN_SYSTEM.md §9/§11 tells (the gradient, the icon-topped card, the "10,000+ teams") checked over the marketing surface as a 0-FAIL build gate.

Changed

  • The Makefile gained the check-website target (gate 14, the docs/WEBSITE/TECHNICAL_ARCHITECTURE.md §5 "a new website-specific lane"): the @vercode/website build + typecheck + the UT-web-* unit suite + the anti-slop lint, the website's verified-state gate.
  • The .env.example + the packages/config KNOWN_VARS gained the 3 website vars (VERCODE_WEBSITE_BASE_URL, VERCODE_WEBSITE_OG_DEFAULT, VERCODE_BEACON_SECRET; the docs/OPERATIONS/ENVIRONMENT_VARIABLES.md §8.5 section).
2026-10-23v0.1.0

The documentation package + the workspace

The doc set and the shared workspace landed: 64 product docs, a 12-doc website package, and packages/contracts as the single source of truth for plan, finding, and webhook shapes.

Added

  • The documentation package: 64 docs across PRODUCT, TECHNICAL, DATABASE, API, SECURITY, DESIGN, TESTING, OPERATIONS, BUSINESS, and IMPLEMENTATION, each validated for cross-reference consistency in docs/DOCUMENTATION_REVIEW.md.
  • The website spec: 12 docs in docs/WEBSITE/ — the P2 launch surface's IA, content schemas, structured-data and SEO/AEO/GEO rules, the route list in docs/WEBSITE/INFORMATION_ARCHITECTURE_AND_PAGES.md.
  • packages/contracts as the single source of truth: Zod schemas for plans, findings, jobs, and webhooks that every app and package imports from — a shape change is one edit, not ten re-declarations.
  • The known-limitations register: L-1 through L-10 in the repo README "Known limitations", each with a landing phase — deferred items are documented, not silently absent.
2026-10-22v0.0.1

Scaffold

The repo is a working scaffold: docs + contracts + a dev-stack; the live pipeline ships behind gate-13.

Added

  • The pnpm monorepo: apps/web (the Next.js dashboard) + apps/api + apps/worker, 12 packages, and a Docker Compose dev-stack.
  • The Tailwind-4 + Next-15 dashboard surface: the six product views — overview, review detail, security rollup, repositories, rules, usage, audit — built against mocked data.
